## Phase 3 — GEO & authority (Week 11–12+)

Citation-worthy content and entity strengthening.

### Step 3.1 — Entity homepage refresh

- **Objective:** Make brand facts extractable for AI systems
- **Tag:** GEO
- **Actions:**
  1. Add definitional paragraph: who, what, founded, HQ, markets
  2. Add dated statistics with sources
  3. Ensure Organization schema matches visible content
- **Acceptance criteria:** Plain-text facts match schema; readable in first 2 scrolls

### Step 3.2 — FAQ / Q&A expansion

- **Objective:** Increase citation surface for common queries
- **Tag:** GEO + SEO
- **Actions:**
  1. Map 10–20 real user questions (support, careers, products)
  2. Publish FAQ page(s) with FAQPage schema
  3. Link from relevant hub pages
- **Acceptance criteria:** FAQ schema valid; questions match search intent

### Step 3.3 — Press & news optimisation

- **Objective:** Fresh, citable news assets
- **Tag:** Both
- **Actions:**
  1. Article schema on all press releases
  2. Unique meta descriptions summarising each article
  3. Internal links from news hub to related about/sustainability pages

---

## Phase 4 — International parity

### Step 4.1 — Locale meta audit

- **Objective:** en / zh-hk / zh-cn have equivalent coverage
- **Actions:**
  1. Export URL + title + description per locale
  2. Flag missing translations and duplicate English stubs
  3. Fix hreflang if locale URL patterns inconsistent
- **Acceptance criteria:** Parity table shows no critical gaps
